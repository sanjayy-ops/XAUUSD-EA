This repository contains the one-year handover package for the MARK 1 EA research project.
The project investigates giveback behavior and the butterfly/cascade effect in a single-position XAUUSD EA.
It includes the EA source, one-year baseline trade data, shadow-signal logs, the baseline Strategy Tester report, and the investigation report.
The one-year shadow log contains 5,605 qualifying signals: 245 executed and 5,360 blocked.
The investigation covers real EA/backtest validation, tick-replay validation, giveback experiments, and meta-labeling iterations.
The ML work includes documented failures, fixes, validation results, and the remaining limitations of the tested feature set.
This package is provided to support independent ML review, critique, and guidance on the next research direction.
